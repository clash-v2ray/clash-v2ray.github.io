Quantumult简介：为什么选择它？

Quantumult是一款专为iOS设备设计的网络代理工具，它不仅支持多种代理协议（如HTTP、HTTPS、SOCKS5等），还具备强大的过滤规则和节点管理功能。与其他代理工具相比，Quantumult的优势在于：

  1. 高效稳定：通过智能路由算法，自动选择最优节点，确保网络连接的低延迟和高速度。
  2. 隐私保护：所有流量均通过代理服务器转发，有效防止数据泄露和网络监控。
  3. 高度自定义：用户可以根据需求添加、删除或修改节点，甚至编写自己的过滤规则。

为什么要添加本地节点？

本地节点通常指的是位于用户所在地区或邻近区域的代理服务器。相比于远程节点，本地节点具有以下优势：

  • 更低的延迟：由于物理距离更近，数据传输时间更短，网页加载和视频缓冲速度更快。
  • 更高的稳定性：本地节点受网络波动影响较小，连接更加可靠。
  • 更好的隐私性：某些情况下，本地节点可以绕过运营商的流量限制或审查。

添加本地节点的完整步骤

第一步：下载与安装Quantumult

  1. 打开App Store，搜索“Quantumult”。
  2. 点击“获取”并完成安装。
  3. 首次启动时，Quantumult可能会请求VPN配置权限，点击“允许”以确保正常使用。

第二步：获取本地节点链接

本地节点的来源通常有以下几种：

  1. 自建节点：如果你有VPS（虚拟专用服务器），可以自行搭建代理服务器并生成节点链接。
  2. 订阅服务：许多代理服务提供商会提供节点订阅链接，直接复制即可使用。
  3. 免费节点分享：部分论坛或社区会分享免费的本地节点链接，但需注意安全性。

第三步：在Quantumult中添加本地节点

  1. 打开Quantumult，点击底部菜单栏的“配置”。
  2. 选择“节点管理”，然后点击右上角的“+”按钮。
  3. 在弹出的界面中，填写以下信息：
    • 名称：为节点起一个易于识别的名字（如“本地节点-上海”）。
    • 服务器地址：填写节点的IP或域名。
    • 端口：输入代理服务器的端口号。
    • 协议：选择对应的代理协议（如HTTP、SOCKS5等）。
    • 其他参数：根据节点提供者的要求填写密码或加密方式。
  4. 点击“保存”完成添加。

第四步：验证节点是否可用

  1. 返回Quantumult主界面，点击“代理”选项卡。
  2. 选择刚刚添加的本地节点。
  3. 打开浏览器或使用Ping工具测试连接是否成功。如果延迟较低且能正常访问网站，说明节点配置正确。

常见问题与解决方案

1. 节点添加后无法连接

  • 检查链接格式：确保服务器地址、端口和协议填写正确。
  • 测试网络环境：尝试切换Wi-Fi或移动数据，排除本地网络问题。
  • 联系节点提供者：如果问题依旧，可能是节点本身失效，需更换链接。

2. 如何更新节点信息

进入“节点管理”，长按需要修改的节点，选择“编辑”即可更新信息。

3. 能否分享节点给他人？

Quantumult支持节点链接导出功能，你可以通过文本或二维码的形式分享给其他用户。

FAQ

Trojan-go 如何启用 WebSocket 支持？
在配置文件中将 transport 参数设置为 websocket，并指定 path 路径。客户端需同步使用相同路径及主机名。这样可将 Trojan 流量伪装为普通 WebSocket 通信以提升隐蔽性。
Sing-box 可以替换 Clash 的 YAML 配置吗？
可以。Sing-box 原生支持解析 Clash YAML 配置，并自动转换为自身 JSON 结构。节点和规则基本兼容，但部分脚本和自定义插件可能需要手动调整。
Potatso Lite 如何结合手动节点选择优化访问？
用户可根据网络延迟和用途手动切换节点，选择最优节点处理不同流量。虽然不支持自动更新，但在节点不稳定或特定需求下可以灵活调整，提高访问效率。
V2Ray 如何设置多入口实现不同访问控制？
通过定义多个 inbound，对不同端口绑定不同的 tag 并在路由中匹配流量。可针对内网用户、远程用户或特定 IP 段应用不同规则，实现灵活访问控制与流量隔离。
Surfboard 的配置文件可以与 Clash 通用吗？
Surfboard 基于 Clash 核心，因此支持大部分 YAML 配置文件，但部分字段如 rule-provider、external-controller 等可能不兼容。建议使用订阅转换工具将 Clash 文件转换为 Surfboard 兼容格式导入。
Mellow 是否支持自定义 DNS？
支持。Mellow 的配置文件中可设置 DNS 服务器地址及模式（如 DoH、DoT）。用户可使用安全 DNS，如 Cloudflare 1.1.1.1 或 Google DNS，以减少污染风险。
VLESS + XTLS 模式在高并发下有什么优势？
XTLS 模式减少握手次数和加密冗余，提高 CPU 利用率和吞吐量。在高并发场景下能保持连接稳定，适合游戏、流媒体和频繁请求的网络环境，提升整体性能。
V2Ray 如何使用 WebSocket 传输？
在 V2Ray 配置文件中将传输方式设置为 ws，即启用 WebSocket 模式。结合 CDN 和 TLS，可实现安全高速的代理链路。WebSocket 常用于伪装成 HTTPS 流量，从而降低被识别风险。
WinXray 的本地 PAC 模式与全局模式有什么区别？
PAC 模式通过规则文件自动判定哪些域名走代理，能兼顾速度与便利；全局模式则所有流量都通过代理，适合调试或访问被完全屏蔽的网络。两者可在界面一键切换，根据需求灵活选择。
SSR 的协议插件如何增强连接稳定性？
SSR 的协议插件可以增加流量的伪装特性，模拟常见协议或浏览器行为，从而降低被识别和封锁的风险。这对不稳定网络或高封锁环境尤其有帮助。
