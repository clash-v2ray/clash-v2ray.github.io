详细配置步骤图解

第一阶段：路由器基础设置

步骤1：刷入增强型固件
1. 访问路由器管理界面（192.168.1.1）
2. 导航至【高级】-【管理】-【固件升级】
3. 上传下载好的Merlin固件（如R7000380.700.chk）
4. 等待约5分钟完成刷机

专业提示：刷机过程中切勿断电，建议使用有线连接操作

步骤2：开启必要功能
1. 启用JFFS分区（用于存储脚本文件）：
【系统管理】-【系统设置】-【Format JFFS partition at next boot】选"是"
2. 开启SSH远程管理：
【系统管理】-【系统设置】-【Enable SSH】选择"LAN only"

第二阶段：科学上网核心配置

方案A：Shadowsocks透明代理（推荐）
1. 通过SSH连接路由器（用户名为admin，密码为管理密码）
2. 安装Entware环境：
bash opkg update && opkg install shadowsocks-libev 3. 配置ss-redir：
json { "server":"your_server_ip", "server_port":443, "password":"your_password", "method":"aes-256-gcm", "timeout":300, "fast_open":true } 4. 设置iptables规则实现全局代理：
bash iptables -t nat -A PREROUTING -p tcp -j SHADOWSOCKS

方案B：OpenVPN客户端配置
1. 下载服务商提供的.ovpn配置文件
2. 在路由器界面进入【VPN】-【OpenVPN客户端】
3. 导入配置文件并启用"自动重连"选项
4. 设置策略路由（仅特定设备走VPN）：
bash ip route add default via $VPN_GW dev tun0 table 100 ip rule add fwmark 0x1 table 100

第三阶段：智能分流设置

为避免国内网站也走代理导致速度下降，需要配置智能分流：

  1. 安装dnsmasq-full替代原DNS服务：
    bash opkg install dnsmasq-full
  2. 配置国内IP段直连：
    bash wget -O /jffs/configs/china_ip.txt https://raw.githubusercontent.com/17mon/china_ip_list/master/china_ip_list.txt
  3. 设置分流规则：
    bash for ip in $(cat /jffs/configs/china_ip.txt); do iptables -t mangle -A SHADOWSOCKS -d $ip -j RETURN done

高级优化技巧

1. 双WAN负载均衡

通过USB 3.0接口接入4G网卡作为备用线路，当主线路故障时自动切换：
bash iptables -A PREROUTING -t mangle -j WANLOADBALANCE

2. 定时重启策略

每周日凌晨3点自动重启：
bash cru a RouterReboot "0 3 * * 0 /sbin/reboot"

3. 流量监控

安装vnStat实时监控流量使用：
bash opkg install vnstat vnstat -l -i tun0

常见问题解决方案

Q1：连接VPN后网速明显下降
A：尝试以下步骤：
1. 更换加密方式（如将AES-256改为CHACHA20）
2. 测试不同服务器节点
3. 检查是否开启硬件加速（【高级】-【LAN配置】）

Q2：部分设备无法科学上网
A：检查：
1. 设备是否被加入了策略路由例外列表
2. 本地DNS是否被污染（建议改用DoH）

Q3：如何实现Netflix跨区观看
A：需要：
1. 确认VPN支持流媒体解锁
2. 在路由器设置DNS覆写：
bash nvram set custom_dns="8.8.8.8,1.1.1.1" nvram commit

FAQ

Nekobox 是否能与其他客户端共存？
可以。Nekobox 配置独立，不影响其他客户端的运行。用户可同时安装 Clash、Mellow 或 Shadowrocket，按需切换使用，互不干扰。
如何把 Clash 规则与本地 hosts 文件结合使用？
可在 Clash 的 rules 中优先设置域名直连规则，并在系统 hosts 中添加常用站点的固定解析以加速 DNS 解析。注意 hosts 优先级高于 DNS，因此修改 hosts 需谨慎以避免与真实解析冲突。
Surfboard 是否支持 Clash 配置？
Surfboard 是一款支持多种协议的客户端应用，它能够兼容 Clash 的配置文件格式，用户只需导入 YAML 文件即可。该应用以轻量、高速著称，常用于 iOS 和 macOS 系统。
Mihomo 的节点管理支持批量操作吗？
Mihomo 支持批量导入、删除和更新节点。通过策略组和分类管理，用户可以高效地管理数百个节点，同时进行测速和节点切换，提高操作效率。
Surfboard 如何在 iPhone 上使用？
从 App Store 下载 Surfboard 后，导入 Clash 订阅链接即可使用。Surfboard 提供直观的节点切换和规则管理界面，可查看实时延迟与流量数据，非常适合希望简单上手的 iOS 用户。
Clash 如何实现延迟自动切换？
Clash 可以结合策略组和延迟检测功能，自动选择延迟最低的节点。保证网页、视频和游戏流量通过最优节点，提高访问速度和稳定性，减少掉线和卡顿。
Mellow TUN 模式如何拦截全局流量？
TUN 模式会拦截系统 IP 层的所有流量，实现全局代理。相比 SOCKS5 只影响部分应用，TUN 可以覆盖游戏、视频和浏览器等所有流量，提高科学上网体验的全面性。
Clash 的延迟检测如何帮助节点选择？
Clash 会定期测速节点延迟，并根据策略组自动选择延迟最低节点处理流量。可避免访问高延迟或失效节点，提高网页、视频和游戏访问速度及稳定性。
Shadowrocket 的分流规则如何实现广告拦截？
通过配置规则，将广告域名或请求路径匹配到黑名单策略，使请求直接阻断或重定向到本地地址。这样用户浏览网页或使用应用时可自动屏蔽大部分广告内容。
Hysteria2 多路复用对高频连接的优势？
多路复用可让多个短连接共享同一通道，减少握手和加密开销，提高吞吐量。适合高频短连接场景，如即时通讯和游戏，保证流量快速、稳定传输。
